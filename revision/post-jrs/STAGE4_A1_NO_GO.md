## 2. Exact Stage-3 model reconstructed: no changed primitives

**Players and timing:** central authority commits `s=(s12,s13)` and financing shares `omega_i=1/3`; three local governments choose `x_i∈[0,1]` simultaneously; the developer chooses `e∈{12,13,∅}`, at most one project, after observing x and s; production and public transfers occur. The developer chooses the strictly largest *positive* net profit, ties between positive-project profits go to 12, and zero-profit projects are not started. This selection is defined for **every** portfolio history (not only equilibrium profiles).

**Exact parameter slice:**

```text
Delta=(1,1/5,1/5),  A12=3, A13=5/2,
K12=K13=1/10, gamma=1/5, alpha=1/2,
omega=(1/3,1/3,1/3),
s12,s13>=0, s12+s13<=1/5.
```

`m12=x1(1-x2), m13=x1(1-x3)`. With grant schedule `s`, developer's project profit:

```text
pi12=(3/5+s12)*m12-1/10
pi13=(1/2+s13)*m13-1/10
pi_none=0.
```

If project `1→j` operates, region `i` gets direct real surplus `Delta_i x_i`, plus `(2/5) A_1j m_1j` if `i=1` or `i=j`, minus taxpayer share `s_1j*m_1j/3`; other region gets its direct surplus minus its own one-third grant tax. Developer gets `(A_1j/5+s_1j)m_1j-1/10`. If none operates, all receive only direct local surplus.

**National resource accounting** (no second count of grant receipts):

```text
SW(x,e) = x1 + (x2+x3)/5 + A_e*x1*(1-xj) - 1/10
          for selected project e=(1,j);
SW(x,none) = x1+(x2+x3)/5.
```

This excludes financing deadweight cost by explicit assumption, not by empirical justification. The national authority is assumed to maximize `SW` with its feasible schedule budget. Real investor effort costs are project-specific `K_e`. Investor profit is national real income, though absent from local government's objective. No households or consumer-demand margin exists; consumer surplus, a demand Hessian and market clearing are **NOT APPLICABLE**.

## 3. Proposition A1-S4-1 (analytical, limited-slice equilibrium)

**Exact statement:**

For the numerical rational primitives and **every** `s12,s13>=0` with `s12+s13<=1/5`, the continuation game in which governments simultaneously choose `x∈[0,1]^3` and the investor follows the project rule above has the following unique pure-strategy Nash outcome:

```text
if s13 - s12 <= 1/10:
   x=(1,0,1), e=12, SW=41/10;
if s13 - s12 > 1/10:
   x=(1,1,0), e=13, SW=18/5.
```

At `s13-s12=1/10`, the investor's project-profit tie when both recipient regions become fully downstream is resolved in favor of project 12; this is essential to the **weak** branch inequality.

**Proof on the complete continuous strategy space:**

**(A) Investor best response everywhere.** After x, compare `pi12,pi13,0` explicitly with the deterministic tie rule. Both profit functions are affine in a unilateral government strategy and define finite project entry/switch boundaries. No subgame or zero-profit/outside-option history is ignored.

**(B) Hub region 1 has strictly dominant `x1=1`.** For fixed x2,x3, write

```text
pi12 = [(3/5+s12)(1-x2)]*x1 - 1/10;
pi13 = [(1/2+s13)(1-x3)]*x1 - 1/10.
```

Because **the project costs are equal**, which project is more profitable for positive x1 depends on x2,x3,s **but not x1**. Varying x1 can only activate the selected project, not switch its identity. In the inactive region `u1=x1`; with an active e it is `u1=x1*[1+c1_e(1-xj)]` where `c1_12=6/5-s12/3>=17/15>0` and `c1_13=1-s13/3>=14/15>0`. Each branch strictly increases in x1 and entry creates a nonnegative upward jump. Therefore the **global** best response is x1=1 regardless of other choices.

**(C) If a project e=(1,j) is active at a candidate Nash profile, its recipient must set `xj=0` and the unused recipient region k must set `xk=1`.** With x1=1, the active recipient's local value is `(1/5)*xj+c_j(1-xj)`, with `c_12=6/5-s12/3>=17/15>1/5` and `c_13=1-s13/3>=14/15>1/5`. Reducing xj both raises this expression and makes **its own project strictly more competitive**, so the active project remains active and xj=0 must hold. The excluded region k, by increasing xk, strictly increases its direct real surplus while *weakening* only the rival project, so it cannot switch away from the currently selected project; its own contribution to taxes is unchanged. Hence xk=1. Both conclusions are global, not just FOCs.

**(D) No-project profiles are never Nash.** Since x1=1 is dominant, if no project is operated, `(3/5+s12)(1-x2)<=1/10`. Region 2 can deviate to `x2=0`, guaranteeing project 12 strictly profitable while project 13 remains nonpositive; its payoff jumps to `6/5-s12/3>=17/15>1/5`, exceeding any prior no-project direct return `x2/5<=1/5`. Therefore every Nash profile activates a project.

**(E) Only two candidate profiles exist**, `P12=(1,0,1)` and `P13=(1,1,0)`. Both have their indicated project active, and the selected downstream player prefers own project to no project (its welfare share exceeds the maximum direct-income alternative). The unused player may switch to its own project by deviating to its downstream role:

```text
at P12, region 3 moving to x3=0:
  pi12 = 1/2+s12;  pi13=2/5+s13.

at P13, region 2 moving to x2=0:
  pi12 = 1/2+s12;  pi13=2/5+s13.
```

When `s13-s12>1/10`, the move from P12 triggers project 13 and region 3 obtains `1-s13/3>=14/15`, strictly above its excluded payoff `1/5-s12/3<=1/5`; P12 fails Nash. Otherwise project 12 remains the winner at all such deviations, so P12 survives. Conversely, at P13 region 2's deviation to x2=0 triggers project 12 iff `s13-s12<=1/10`, yielding `6/5-s12/3>=17/15` rather than the excluded payoff `1/5-s13/3<=1/5`; P13 then fails Nash. Otherwise P13 survives. The hub and incumbent recipient have no profitable deviations by (B)/(C). Exact boundary and full interval are covered.

**Conclusion:** exactly one pure equilibrium at every funding schedule in this *restricted* budget triangle. This supplies pure continuation after each grant history in the stated triangle, not a proof for arbitrary A1 parameters or unrestricted fiscal policy domains.

## 4. Proposition A1-S4-2 (central optimum and constrained social planner)

The project-selection/portfolio benchmark permits `e=12`, `e=13` or `e=none`, with the same real technology, capacity and setup costs. On each fixed-e branch the social objective is bilinear in x1,xj and linear in the excluded region's own x; positive `Delta_i` makes x1=1, the excluded region xk=1, and because `A_e>1/5` it makes chosen downstream xj=0. The complete attainable maxima are:

| Project branch | Joint planner x | Maximum national real welfare |
|---|---|---:|
| e=12 | (1,0,1) | `41/10=4.1` |
| e=13 | (1,1,0) | `18/5=3.6` |
| none | (1,1,1) | `7/5=1.4` |

Thus the benchmark optimum is exactly P12 and **already privately investable** at zero grant: `pi12=1/2>0`. It can be implemented by `s12=s13=0`, which yields the unique Nash continuation P12 by Proposition A1-S4-1. Under a national authority maximizing modeled `SW`, **every** feasible grant schedule with `s13-s12<=1/10` is optimal, yielding welfare 4.1; all grant schedules with `s13-s12>1/10` yield 3.6. Zero is weakly optimal and avoids a need for fiscal appropriations, despite multiple equivalent welfare-maximizing schedules.

**Equilibrium notion:** conditional on the national social-welfare objective, investor tie rule and budget `B=1/5`, this completely characterizes pure SPNE continuation behavior and central policies for the restricted parameter slice. The national grant is a commitment choice; it is not a two-government voluntary transfer. No claim of generic SPNE existence for other parameters.

**Interpretation:** the Stage-3 witness is a case of a grant **diverting** private project choice away from the jointly optimal partner, rather than remedying an uninternalized baseline policy wedge. It does not prove every grant harms welfare: the range `s13-s12<=1/10` has the same welfare as zero subsidy.

## 5. The decisive nested-benchmark absorption test

### N1: fixed regional portfolios (kills the purported full-game-only welfare finding)

Freeze `x=(1,0,0)`, **before** allowing the investor to choose 12 or 13; no government's `x` can react to grants. Project profits are:

```text
pi12=1/2+s12; pi13=2/5+s13.
```

The investor's winner switches at the **identical** grant boundary `s13-s12>1/10`, and national modeled welfare is:

```text
SW_N1(project 12)=1+3-1/10=39/10=3.9
SW_N1(project 13)=1+5/2-1/10=34/10=3.4
difference=1/2.
```

Exactly the same `1/2` welfare loss occurs with **no governmental role response**. In the full game, the *nonselected* downstream region additionally chooses U and gains `1/5` in either regime. Thus the incremental endogenous government response cancels in the comparison, and the full-game welfare effect is the **same old private project diversion** as N1.

For more general role premiums `Delta_2, Delta_3`, the difference between full-profile welfare gaps and the fixed-`x=(1,0,0)` gap is `Delta_3-Delta_2`. Hence under the Stage-3 symmetry `Delta_2=Delta_3`, there is **no interaction-generated welfare wedge**. Altering `Delta_i` solely to force one would be the Stage-2-killed H07 mechanical heterogeneity extension.

### N0: project identity frozen

Fix e=12 with viable production and grants. With the screened inequality `c_{12}>1/5`, the recipient chooses `x2=0`, the uninvolved region chooses `x3=1`, and the upstream hub `x1=1`; e13 analogously selects `(1,1,0)`. The fundamental local allocation response is ordinary complementary-input prioritization **once the partner is fixed**.

### N2: zero co-financing

With `s=0`, the model already implements social optimum P12 with no new instrument. The project's correct partner and regional role are the unique decentralized equilibrium. Therefore the model does not explain a **policy-internalization deficiency** under its test parameters.

### N3: no exclusivity

Allow the two independently profitable projects to operate simultaneously with separate real setup costs and financing, retaining separate expected matching masses. At `s=0`, both projects can operate at `x=(1,0,0)`; each downstream region prefers its complementary role and the hub prefers upstream. This is a Nash profile in the nonexclusive extension. National real surplus is `1+3+5/2-2/10=63/10=6.3`. Hence a single-project constraint creates project crowding-out, but this is a **capacity/project-selection bottleneck**, not itself a novel intergovernmental externality result.

### N4: relation to original frozen theory

The original **two-region symmetric simultaneous game** is not literally nested in the three-government/private-investor/exclusive-link model by setting `s=0` or `K=0`. Restoring its bilateral matching and local factor-income incidence requires changing the actors, production and timing. **This is a structural scope break**, another reason A1 is a risky revision to the original JRS paper rather than a natural repair.

## 7. Globality, continuation, off-path and accounting log

- **Local policy strategies:** continuous full `[0,1]^3`, not merely binary restrictions. The proof above excludes interior equilibria by global monotonic deviation arguments; the exact-rational independent evaluator checks every point where the investor's selected project or entry can change, including left/right affine branch limits.
- **Boundary/tie:** `s13-s12=1/10` is intentionally weak for the e12 branch because investor ties go to 12; `pi_e=0` goes to no project. The national authority picks schedules from a compact triangle; the continuation map is well-defined for all schedules in this **restricted** slice.
- **Participation:** developer chooses outside option `0` if both projects yield nonpositive profit. No additional voluntary regional project-signature right, firm financing, project-capacity purchase/ownership, tax collection enforcement or match-investment IR constraints are modeled. Therefore no practical I3 implementation claim.
- **Fiscal accounting:** `sum tau_i=s_e*m_e`; the same grant enters developer profit positively and local governments' tax liabilities negatively; `SW=` local payoffs + developer profit, not including grant twice; `K_e` is a real cost; regional policy shares x are *not* cash budgets.
- **Concavity/SOCs:** each private payoff is affine in its own portfolio within any fixed investor-outcome branch; classical strict SOCs are not the justification. Piecewise project selection creates kinks/discontinuities; global branch/deviation comparisons were used. Planner uses bilinear fixed-e expressions and corner comparisons, not an invented global Hessian-concavity assumption.
- **Solver outcomes:** every fixed grant history in this B=1/5 parameter slice `SOLVED_EQUILIBRIUM` with exactly one pure regional Nash (by analytic proof). No unresolved continuation **within this slice**. Outside the slice, arbitrary-grant and parameter continuation taxonomy is `UNRESOLVED`, not a license for a universal SPNE theorem.
- **Independent verification limits:** one self-contained exact-rational evaluator sampled 237 legal grant schedules, all three players' feasible continuous deviations from both profiles, and model/frozen-portfolio welfare-accounting identity. This is algebraic regression corroboration, **not an independent Stage-4A referee certification**. Existing Stage-3 code used a different organization of the same underlying payoff, and is not a separate proof method by itself.
- **Computational scope:** sample grid does not prove universality; the proof is supplied analytically above. Scripts are not an exhaustive theoretical proof for general parameter space. No Lean rebuild and no CI run were performed.
- **Consumer surplus/demand:** NOT APPLICABLE given absence of consumer market/demand in A1. `KKT`: no planner interior optimum requiring it in this exact comparison; corners verified directly.
