## 2. Model-to-theorem differences that matter

**2026 ABT restriction:** constant static/dynamic subsidies depend critically on the CES proportionality; the authors explicitly discuss possibility of gap-specific/time-varying subsidy outside that restriction, *without asserting those cases lack solutions*. The unicity result (Prop.16) is in a REDUCED 1-dimensional adoption/capital aggregation under aggregate concavity `ζ≤1`; it is **not** an all-sector arbitrary directed networks uniqueness theorem.

**2024 BT restriction:** sector heterogeneity is explicit via separate production shares `Ω`, adoption-good shares `Λ`, sector modern shares `M`, with a policy-to-adoption Jacobian built as an inverse operator (Prop.2). Crucially, a local differentiable mapping/linearized response is NOT a global dynamic equilibrium/uniqueness result. Any purported theorem must distinguish *existence of static response*, *invertibility of local comparative-statics matrix*, *global uniqueness of an equilibrium* and *unique implementation of first-best dynamic PATHS*.

### X1: An immediate theorem is already generic matrix analysis

For any nonlinear multi-sector static adoption fixed point `a=F(a;s)`, let `J=I-D_aF(a_0;s_0)`. If `J` is invertible, the **Implicit Function Theorem** provides a locally unique differentiable BRANCH `a(s)` near `(a_0,s_0)`, with `D_s a = J^{-1} D_sF`. This is valid under routine smoothness, but **DOES NOT establish GLOBAL uniqueness or prevent other equilibrium branches elsewhere**. If `||D_aF||<1` uniformly over a compact convex invariant domain in a compatible norm, standard contraction gives existence and uniqueness globally in that STATIC fixed-point problem. If `J` is singular, neither multiplicity nor absence follows without further arguments.

These are standard IFT / Banach fixed-point implications, not publishable new theorem statements. They are included as hard-negative controls to prevent dressing a sector-specific inverse Jacobian as a novel economic result. **Do not misapply static contraction as proof of DYNAMIC saddle path uniqueness** in ABT's intertemporal equilibrium. An actual dynamic uniqueness theorem would need state laws, forward-looking household FOCs/transversality and correct global restrictions.

### X2: Unjustified shortcuts to reject

- 'Break CES so optimal subsidies are no longer constant': directly anticipated in ABT p21 original explanatory text; merely showing subsidy time dependence from nonlinear shares is NOT a new general theorem.
- 'Add production and investment networks': in BT 2024 Proposition 2.
- 'Replace scalar complementarity ζ with a matrix/spectral radius': one must state how a full dynamic GE problem maps to that spectral object and why existing network M-matrix or contraction theory does not already settle it. A spectral radius inequality by itself is NOT a novel JME/JET result.
- 'Add a fiscal regional game and output a local-vs-global wedge': Ogawa/Wildasin, Kondo, Ferrari/Ossa and 2025 Bai/Jin/Lu/Wang already offer nearby conceptual models; prove exact new regime or stop.
- 'Absence of an instrument implementing all equilibria': ABT distinguish 2 standard subsidies for implementing an efficient equilibrium vs optional TEMPORARY supplementary intervention to secure **unique** implementation; do not misquote Prop.6 as universal unique/full optimality.

## 3. The only narrowly formulable T-DYN `Delta Card` (UNPROVED)

**One substantive change to investigate** is to allow heterogeneous sector-specific adoption state paths and input networks (already in BT) **within a forward-looking decentralized dynamic implementation problem**, then ask whether a **necessary/sufficient economically meaningful condition** on the intersectoral feedback identifies failure or preservation of optimal subsidies' unique-implementation property, beyond scalar ζ and beyond routine monotone matrix theory. Government strategic rivalry is **not** added automatically: this is an independent general-economic-theory route unless a credible economics interpretation demands governments.
