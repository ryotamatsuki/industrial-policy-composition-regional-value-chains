# JRS Stage-14 source-package inventory

The actual reviewer-facing archives are generated by `submission/jrs/build_submission_package.py` from an explicit allow-list. Internal workflow records and unblinded author materials are therefore excluded by construction.

## 1. Blinded LaTeX main-document archive

Generated filename: `JRS_Blinded_LaTeX_Source.zip`

Contents:

- `paper/main.tex` — blinded manuscript source with empty `\author{}`;
- `paper/main.pdf` — PDF compiled from the packaged sources;
- `paper/sections/*.tex` — all manuscript sections including declarations and analytical appendix;
- `references/references.bib` — only bibliography records actually cited by the manuscript;
- `figures/phase_regions.tex` — deterministic manuscript figure source;
- `figures/phase_regions.svg` — deterministic vector companion;
- `tables/thresholds.tex` — deterministic table source.

The archive intentionally excludes:

- `THEORY_FREEZE.md`, `STATUS.md`, `docs/**`, research notes and stage reports;
- `.git/**`, `.github/**`, GitHub metadata and workflow files;
- unblinded title-page material;
- cover-letter drafts;
- author-specific metadata/declarations;
- public repository URLs;
- Lean build caches and Python caches;
- secrets/private correspondence.

The CI gate extracts this exact zip into a fresh temporary directory and recompiles it with `pdflatex -> bibtex -> pdflatex -> pdflatex`. Undefined citations/references, nonblank PDF Author metadata, author-identifying tokens, non-embedded PDF fonts, archive-size violations, and build failures are fatal.

## 2. Peer-review PDF

Generated filename: `JRS_Manuscript_for_Peer_Review.pdf`

This is byte-for-byte copied from the PDF produced by the allowed blinded source suite before the clean-extraction repeat build. Stage 14 separately checks metadata, embedded fonts, page count, text anonymity, and every page visually.

## 3. Separate line-art figure

Generated filename: `Figure_1.pdf`

This is a vector PDF derivative built from the same deterministic `figures/phase_regions.tex` content. It does not introduce a second figure or change the figure's data, labels, thresholds, scope, or caption. It exists solely to satisfy the current Wiley/JRS preference for separate high-quality line art while retaining the embedded figure in the Free Format review PDF.

## 4. Anonymous supporting-information archive

Generated filename: `JRS_Anonymous_Supporting_Information.zip`

Static Python material from `submission/jrs/supporting_information/`:

- `README.md`;
- `requirements.txt`;
- `model/baseline.py`;
- `verify_symbolic.py`;
- `tests/test_regressions.py`;
- `tests/test_claim_scope_counterexamples.py`;
- `generate_outputs.py`.

Generated deterministic exposition outputs are included after execution.

The package builder also copies the exact canonical Lean source into an anonymous `lean/` directory at build time:

- `IPCRVC.lean`;
- all `IPCRVC/*.lean` modules;
- `lean-toolchain`;
- `lakefile.toml`;
- `lake-manifest.json`;
- generated anonymous Lean README.

The anonymous SI archive excludes repository-owner names/URLs, author metadata, unblinded submission files, workflow/stage notes, caches, and Git metadata. Python symbolic/regression/counterexample checks and deterministic generation are re-run inside the staged SI. The exact canonical Lean tree is independently subjected to `lake build --wfail` in the Lean CI job.

## 5. Files NOT yet submission-ready because they require author input

The following are deliberately not generated as final upload files in Stage 14:

- final unblinded title-page PDF/source;
- final signed/author-completed cover letter;
- ORCID and author/contact portal records;
- funding and competing-interest declarations;
- non-AI acknowledgments;
- exact AI model/version(s) and access period;
- preprint/prior-dissemination and exclusive-submission attestations.

These are `AUTHOR CONFIRMATION REQUIRED` items for Stage 15; they must not be inferred.

## 6. Build provenance

CI emits `submission/jrs/build/BUILD_PROVENANCE.txt` inside the Stage-14 artifact. It records the exact GitHub Actions `GITHUB_SHA`, Python version, manuscript page count, bibliography counts, hashes of generated files/archives/PDFs, deterministic-output hashes, and any LaTeX box warnings.
