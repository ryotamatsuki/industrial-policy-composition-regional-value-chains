# Symbolic Verification

Stage 9 symbolic verification belongs here.

Minimum targets:

1. Reproduce the payoff-difference identity.
2. Reproduce the best-response threshold `q = alpha + Delta/A`.
3. Verify `A^N = Delta/(1-alpha)`.
4. Verify the planner welfare identity and `A^P = Delta`.
5. Verify `A^P < A^N` for `Delta>0`, `0<alpha<1`.
6. Verify the intermediate-region welfare loss `L=A-Delta`.
7. Verify the high-A symmetric equilibrium welfare gap.
8. Verify the restricted CRS and admissible CES robustness identities.

All symbolic checks must use exact arithmetic where feasible and must fail closed.
